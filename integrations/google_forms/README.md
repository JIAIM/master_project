# Експорт тесту в Google Форми

Бекенд надсилає тест у JSON на веб-застосунок Google Apps Script, а той створює форму
в режимі тесту на Google-акаунті власника скрипта. OAuth і Google Cloud проєкт не потрібні.

## Налаштування (один раз, ~5 хвилин)

1. Відкрийте https://script.google.com → **Новий проєкт**.
2. Замініть вміст `Code.gs` кодом із файлу `Code.gs` поруч.
3. **Налаштування проєкту** (шестерня) → **Властивості скрипта** → додайте властивість
   `EDUTEST_SECRET` із будь-яким довгим випадковим рядком.
4. **Розгорнути → Нове розгортання** → тип **Веб-застосунок**:
   - «Виконувати як»: **Я**
   - «Хто має доступ»: **Усі**
   → **Розгорнути**, надайте дозволи (Google попросить доступ до Форм і Диска).
5. Скопіюйте **URL веб-застосунку** (закінчується на `/exec`) і впишіть у `.env` проєкту:

   ```
   GOOGLE_APPS_SCRIPT_URL=https://script.google.com/macros/s/.../exec
   GOOGLE_APPS_SCRIPT_SECRET=той самий рядок, що в EDUTEST_SECRET
   ```

6. Перезапустіть backend: `docker compose up -d --force-recreate backend`.

Після зміни коду скрипта потрібне **нове розгортання** (або «Керувати розгортаннями → Редагувати →
Нова версія»), інакше Google продовжить виконувати стару версію.

## Що створюється

- Форма в режимі тесту: 1 бал за питання, правильні відповіді позначені, пояснення — як відгук.
- Збирається email студента, повторне редагування відповідей вимкнене.
- Викладач (email його акаунта EduTest) стає редактором форми. Якщо цей email не є Google-акаунтом,
  доступ на редагування відкривається за посиланням — тоді не поширюйте посилання для редагування.

Відповіді студентів у Google Формі залишаються в Google: прокторинг, аналіз якості питань та IRT
працюють лише для тестів, пройдених у самій платформі EduTest.
